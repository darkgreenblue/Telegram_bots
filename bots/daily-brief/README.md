# 🎧 daily-brief — پادکست آموزشی روزانه

ربات تلگرامِ شخصی که هر روز صبح یک قسمت پادکستِ آموزشی می‌سازد و می‌فرستد. محتوا از پیجِ
«دستیار آموزشی» در Notion می‌آید، متن با OpenRouter نوشته می‌شود و صدا با یکی از موتورهای TTS.

**فقط برای ادمین‌ها کار می‌کند** (`ADMIN_IDS`). بقیه پیامِ «این ربات خصوصی است» می‌گیرند.

## راه‌اندازی

۱. سه Secret در گیت‌هاب بساز (چهارمی اختیاری است):

| Secret | از کجا |
|--------|--------|
| `DAILY_BRIEF_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) |
| `DAILY_BRIEF_OPENROUTER_KEY` | [openrouter.ai/keys](https://openrouter.ai/keys) |
| `DAILY_BRIEF_NOTION_TOKEN` | یک Internal Integration در [notion.so/my-integrations](https://www.notion.so/my-integrations) |
| `DAILY_BRIEF_ELEVENLABS_KEY` | اختیاری — [elevenlabs.io](https://elevenlabs.io) (موتور صدای سوم) |

۲. در Notion پیجی به نامِ **«دستیار آموزشی»** بساز و از منویِ `...` → `Connections` آن را با
همان Integration به اشتراک بگذار (وگرنه ربات پیج را نمی‌بیند).

۳. ساختارِ پیج (جزئیاتِ کامل در `CLAUDE.md`):

```
📄 دستیار آموزشی
 └─ 📄 معماری نرم‌افزار          ← هر زیرصفحه یک موضوع
      هدف: می‌خواهم سیستم‌های توزیع‌شده را عمیق بفهمم
      عمق: متوسط
      منابع: کتاب Designing Data-Intensive Applications
      ## رودمپ جلسات
      ☐ جلسه ۱: چرا سیستم توزیع‌شده سخت است
      ☐ جلسه ۲: مدل‌های سازگاری
```

۴. merge کن. deploy خودکار `.env` را می‌سازد و ربات را بالا می‌آورد.

## استفاده

| دکمه / دستور | کار |
|---|---|
| `🎧 همین حالا بساز` یا `/now` | همین حالا یک قسمت از جلسه‌ی بعدی بساز |
| `📚 وضعیت رودمپ` یا `/roadmap` | پیشرفتِ هر موضوع + جلسه‌ی بعدی |
| `⚙️ تنظیمات` یا `/settings` | ساعت، روزها، مدت، «فقط فردا»، قالب، موتور صدا |
| `💸 هزینه‌ها` یا `/cost` | هزینه‌ی این ماه و کل، به تفکیکِ موتور صدا |
| `/bakeoff` | یک متنِ نمونه را با همه‌ی موتورها بساز و با گوشِ خودت انتخاب کن |
| `/retry` | تلاشِ دوباره روی آخرین قسمتِ شکست‌خورده |

پیش‌فرض: شنبه تا چهارشنبه، ساعت ۰۷:۳۰ تهران، ۱۵ دقیقه. ساختِ قسمت ۱۵ دقیقه قبل شروع
می‌شود تا فایل رأسِ ساعت آماده باشد.

## نیازمندی‌ها
Node ≥ ۲۰ و `ffmpeg`/`ffprobe` روی سرور (برای چسباندنِ تکه‌های صوتی).
