# Discovery source acknowledgements
The discovery implementation is maintained in this repository. Selected source files from the projects below were reviewed for architecture, public-profile parsing, graph expansion and failure handling. Upstream codebases were not imported wholesale and their test suites were not executed. Non-MIT code was not copied. The pinned revisions and observed license files are recorded in `DISCOVERY-BENCHMARK.json`.
