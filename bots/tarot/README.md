# 🔮 Tarot Bot — ربات فال تاروت فارسی

بازسازی تجربه‌ی یک تاروت‌خوان حرفه‌ای در تلگرام: پرسشنامه‌ی تمرکز، فضاسازی و تمرین تنفس، بُر زدن با توقفِ کاربر، انتخاب کارت از گرید، افشای مرحله‌ای با افکت spoiler، حلقه‌ی بازخورد وسط خوانش، سه قدم عملی، مدیاگروپ یادگاری و قلاب بازگشت ۱۴روزه. مغز فالگیر: `google/gemini-2.5-flash` از OpenRouter.

## اجرا
```bash
cp .env.example .env   # BOT_TOKEN و OPENROUTER_API_KEY را پر کن
npm ci
node index.js
```

## تصاویر کارت‌ها
۷۹ تصویر public-domain دک Rider–Waite ۱۹۰۹ (۷۸ کارت + پشت کارت) در `assets/cards/` کامیت شده‌اند. برای بازتولید:
```bash
npm run fetch-cards   # دانلود از Wikimedia Commons + فشرده‌سازی >۱۰۰KB با sharp (devDependency)
```

## چندزبانه
هر زبان = یک ربات تلگرام جدا (بدون مرحله‌ی انتخاب زبان):
- همه‌ی متن‌ها و پرامپت‌های LLM در `locales/<LOCALE>.js`
- `LOCALE=fa` (پیش‌فرض) و `ENV_FILE` برای چند instance از یک پوشه
- دیتابیس هر زبان جدا است: `data/bot-<LOCALE>.db`

زبان جدید: `locales/en.js` بساز + در `ecosystem.config.cjs` یک اپ جدید با `env: { ENV_FILE: '.env.en' }` اضافه کن.

## بیزینس مدل
- هدیه‌ی خوش‌آمد ۳۰٬۰۰۰ تومانی (دقیقاً یک فال سه‌کارتی) + کارت روز رایگان (روزی یک‌بار)
- کیف‌پول با شارژ کارت‌به‌کارت و تأیید ادمین؛ پی‌وال بعد از انتخاب کارت‌ها و قبل از افشا
- کد تخفیف ۲۰٪ بعد از اولین فال + رفرال دوطرفه ۱۰٬۰۰۰ تومانی

## ادمین
`/stats` آمار درآمد و فال‌ها؛ `/newcode CODE PERCENT DAYS [USER_ID]` ساخت کد تخفیف (کد ۱۰۰٪ = تأیید خودکار بدون رسید).

## فاز تست
`TEST_PHASE = true` در `index.js`: دکمه‌ی «🔄 ریست ربات (تست)» برای همه فعال است. **قبل از انتشار عمومی false شود.**
